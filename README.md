# ESP32-C3 摄影测光表

一个基于 **ESP32-C3 SuperMini** 的便携式摄影测光表。使用数字光照传感器自动测光，实时计算曝光参数，并通过 1.3 英寸 OLED 屏显示。旋转编码器操作，无需按键面板。

> 为胶片摄影设计：带上一台测光表，比掏出手机 App 更可靠，也更符合胶片机的使用习惯。

---

## 功能特性

- **自动测光** — BH1750 数字光照传感器，1 秒刷新，量程 1~65535 lx
- **曝光计算** — 依据 EV100 = log₂(lux / 2.5) 计算，自动考虑 ISO 与滤镜衰减
- **六种拍摄档位**
  - `P` 程序优先 — 用户手动指定的项目固定，其余由程序用安全值补齐
  - `A` 全自动 — 短按一次直接测光出参数
  - `AV` 光圈优先 — 固定光圈，自动求快门 / ISO
  - `TV` 快门优先 — 固定快门，自动求光圈 / ISO
  - `M` 全手动 — 全部手调，只显示曝光偏差
  - `OFF` 关机
- **曝光偏差指示** — 顶栏实时显示 EV 偏差值，`OK` 表示准确
- **安全边界保护** — 快门不慢于 1/250、ISO 不高于 6400、光圈不高于 f/8，越界时偏差闪烁报警
- **滤镜补偿** — 支持 ND2 / ND4 / ND8 / ND16 / ND32 / CPL
- **自动对比度** — 根据环境光强度自适应屏幕对比度
- **电池计时显示** — 左上角四格电池图标，按运行时长估算剩余电量
- **息屏省电** — 30 秒无操作自动关屏，旋转或按键唤醒

## 硬件

### 元器件清单

| 元件 | 型号 / 规格 |
|---|---|
| 主控 | ESP32-C3 SuperMini |
| 显示屏 | 1.3" OLED，SH1106 驱动，128×64，I2C |
| 光照传感器 | GY-30 / BH1750（I2C，地址 0x23） |
| 旋转编码器 | EC11，带按压开关 |
| 供电 | 单节 3.7V 锂电池 + 充电模块 |

### 接线表

| 功能 | ESP32-C3 引脚 | 说明 |
|---|---|---|
| OLED SDA | GPIO4 | 与 BH1750 共用 I2C |
| OLED SCL | GPIO5 | 400 kHz |
| BH1750 | 共用 I2C | 地址 0x23 |
| EC11 A | GPIO6 | 编码器 A 相 |
| EC11 B | GPIO7 | 编码器 B 相 |
| EC11 PUSH | GPIO10 | 带按压开关 |

I2C 总线（OLED 与 BH1750）共用 GPIO4 / GPIO5，OLED 地址 0x3C。

## 操作说明

### 开机 / 关机

- **长按编码器按压键 1.5 秒** — 开机，进入主界面
- **开机后长按 1.5 秒** — 进入模式选择页；在模式页选中 `OFF` 并按压确认即关机

### 主界面

- **短按** — 切换当前编辑字段（`SHUTTER` → `APERT` → `ISO` → `FILTER`，受档位限制）
- **旋转** — 修改当前字段的值
- **30 秒无操作** — 自动息屏，旋转或按键唤醒

### 屏幕布局

```
┌──────────────────────────────────────┐
│ 🔋  +0.3  │  320 lx  │           M   │  ← 顶栏：电池 / 偏差 / 光照 / 模式
├──────────────────────────────────────┤
│ SHUTTER                    1/125     │
│ APERT                      f/5.6     │
│ ISO                          100     │
│ FILTER                      NONE     │
└──────────────────────────────────────┘
```

- **电池图标** — 4 格电量，按运行时长递减；空电时闪烁提示
- **偏差值** — `OK` 表示曝光准确；正数过曝、负数欠曝；超出安全边界时闪烁
- **光照值** — 当前环境光照强度（lux）
- **模式字母** — 当前拍摄档位

## 电池计时说明

由于本项目未使用电量计芯片，电量采用**运行时长估算**：

- **上电 / 断电重插 = 满电 4 格**（物理断电即视为更换电池）
- 每运行 **1 小时**掉 1 格
- **4 小时后**显示空电池图标并闪烁

> 该方案假设放电电流恒定。实测在屏幕常亮、无低功耗优化的情况下，200 mAh 电池约可运行 4 小时。若修改固件显著改变功耗，需重新标定此基准。

## 编译与烧录

### 环境要求

- **Arduino IDE**（或 arduino-cli）
- **ESP32 开发板支持包**（Espressif，建议 3.x）

### 开发板设置

| 项 | 值 |
|---|---|
| 开发板 | ESP32C3 Dev Module（或 `nologo_esp32c3_super_mini`） |
| USB CDC On Boot | **Enabled**（必须开，否则串口不工作） |
| Flash Size | 4MB |

### 依赖库

- **U8g2**（图形库，Arduino 库管理器安装）
- **Wire**（内置）

### arduino-cli 命令行编译

```bash
arduino-cli compile -b esp32:esp32:nologo_esp32c3_super_mini:CDCOnBoot=cdc ./lightmeter_v01

arduino-cli upload -p COM3 -b esp32:esp32:nologo_esp32c3_super_mini:CDCOnBoot=cdc --input-dir ./build ./lightmeter_v01
```

## 实现要点

- **编码器读取** — GPIO 中断驱动 + 四状态查表，配合 4ms 去抖。EC11 一个机械咔哒对应完整四状态循环（2 个有效 delta），累积 ±2 才计为一步，避免一格跳两值
- **屏幕刷新** — SH1106 采用分页发送而非整帧刷新，注意列地址从 `0x02` 起（132 列显存 vs 128 列屏），否则会出现画面横向抖动
- **非阻塞测光** — BH1750 采用「触发 → 延时 → 读取」的非阻塞状态机，不阻塞主循环
- **闪烁实现** — 所有闪烁均基于绝对时间相位（`millis() / 400 & 1`），与重绘频率解耦
- **无高频串口输出** — 正式固件移除了所有高频调试打印，避免 USB CDC 缓冲填满后阻塞主循环

## 踩坑记录

开发过程中遇到的几个典型问题，供参考：

1. **I2C 设备时好时坏** → 优先怀疑物理接触（排针 / 杜邦线），而不是驱动或地址
2. **OLED 上电比 MCU 慢** → 首次 I2C 扫描可能扫不到 0x3C，需要轮询等待几秒
3. **屏幕画面横向抖动** → SH1106 列偏移问题，列地址需从 `0x02` 起
4. **串口读取时旋钮才灵敏** → `Serial.printf` 在无人读取时缓冲填满会阻塞主循环，正式固件应移除高频打印
